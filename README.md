# AutoLux Next — démonstration

Application web de démonstration (PWA) d'un concept de réservation de taxis premium pour Taxis Autolux, Bruxelles.
Toutes les données sont fictives : aucune course réelle, aucun paiement réel, aucune connexion au dispatching.

Ce dépôt contient uniquement l'application compilée, publiée via GitHub Pages.
